# Standard icon names -> Lucide icon (https://lucide.dev/icons/<name>).
# Each line: <context> <freedesktop-name> <lucide-name> [colour]
#   context: actions status devices emblems places mimetypes
#   colour:  accent (default) | warning | danger | success | fg   (theme.nix ui.*)
# Every name is built twice: a normal icon in that colour, and <name>-symbolic,
# outlined to filled paths so GTK can recolour it to the text colour.
# Edit a line and rebuild to swap an icon.
